# Analysis request

Copy this template for any question to the COO's office that needs data. Fill in the first part before any analysis starts; the analyst fills in the second.

## To be filled in by the person asking

| | |
|---|---|
| **Question** (one sentence) | |
| **Asked by / function** | |
| **Decision it supports** | What will be decided, and by whom |
| **Needed by** | Date |
| **Scope** | Period, region, category, channel |
| **What a useful answer looks like** | A number, a ranked list, a yes/no, a chart |

## To be filled in by the analyst

| | |
|---|---|
| **Data used** | Views or tables (see docs/data_dictionary.md) |
| **Method** | How the answer was worked out, in two or three lines |
| **Answer** | Two lines, with the number |
| **Checks** | What the answer was checked against (ledger, another view, last month) |
| **Limits** | What the data cannot show |
| **Query** | Saved in the ad hoc log (docs/adhoc_log.md) |
| **Time taken** | |
